# Assignment 2: Control Structures in Python

This repository contains the Python scripts for **Module 3: Control Structures in Python**. The assignment consists of two tasks designed to demonstrate the use of `if-else` statements and loops,.

## Repository Contents

*   ` Even or Odd.py`: A script to check if a number is even or odd.
*   `sum of integers.py`: A script to calculate the sum of integers from 1 to 50.

---

## Task 1: Check if a Number is Even or Odd

### Description
This program performs the following steps:
1.  Takes an integer input from the user.
2.  Checks whether the number is even or odd using an `if-else` statement.
3.  Displays the result to the console.



---

## Task 2: Sum of Integers from 1 to 50

### Description
This program performs the following steps:
1.  Uses a `for` loop to iterate over numbers from 1 to 50.
2.  Calculates the sum of all integers in this range.
3.  Displays the final sum,.
